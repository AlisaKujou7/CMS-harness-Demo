## Contract

**สถานะ:** อนุมัติแล้ว

### ขอบเขต

1. **ข้อ 1:** hook อ่านคำสั่งใน `bash -c`, `sh -c`, `eval` และข้อความในเครื่องหมายคำพูดหลังคำสั่งเหล่านั้น ถ้าเจอ `git commit` หรือ `git push` ให้ตัดสินเหมือนเรียกตรง
   ถ้าข้อความดิบมี `git commit` แต่ตัวที่ตัดข้อความในเครื่องหมายคำพูดออกไม่มี และไม่ใช่สามแบบข้างบน ให้ `ask` แทน `allow`
2. **ข้อ 4a:** อ่าน `red` หรือ `green` จากข้อความ `-m` แรกเท่านั้น
3. **ข้อ 4b:** นับ `HUSKY=0` ว่าเป็นการข้าม git hook
4. **ข้อ 3:** ไฟล์ `.md` ใน `AIAGENT_POC/` ต้องรัน gate ใหม่เหมือนโค้ด
5. **ข้อ 5:** stamp บันทึกขั้นที่ SKIP และ hook ปฏิเสธ commit ถ้าขั้น `secrets` ถูกข้าม ส่วนการปลอม stamp บันทึกเป็นข้อจำกัดใน ADR
6. **ข้อ 6:** เพิ่ม `openapi` ใน job `Static checks` ของ `pr-gate.yml`
7. **ข้อ 2:** `init.sh` หยุดพร้อมบอกเหตุผล ถ้า Node ไม่ตรง `.nvmrc` หรือไม่มี pnpm และ `CLAUDE.md` แยกส่วนของ Windows ให้ชัดว่าใช้เฉพาะเครื่องนั้น
8. **ข้อ 8:** `workflow.md` กำหนดว่างานไหนไม่ต้องมี Ticket คือแก้เฉพาะ `.md` นอก `AIAGENT_POC/` และไม่เปลี่ยนกฎหรือขอบเขตงาน
9. **ข้อ 11:** ข้อความใน heredoc ที่ป้อนให้คำสั่งอื่นที่ไม่ใช่ `git` ไม่ถูกนับเป็นคำสั่ง
10. ADR-0019 บันทึกการเปลี่ยน gate และเพิ่มกรณีใน `gate:self-test`

### นอกขอบเขต

- ข้อ 4c จำกัด `red` ให้มีแต่ไฟล์เทสต์ เพราะ Red ต้องมีโครงที่ throw ซึ่งเป็นไฟล์โค้ด ผู้ใช้เลือกไม่แก้ไว้แล้วใน T-005
- ข้อ 4d เพราะเป็นไปตามที่ออกแบบ
- ข้อ 9 ไม่ติ๊ก DoD ของ T-001 ถึง T-003 ย้อนหลัง เพราะจะดูเหมือนติ๊กในวันนั้น จะเขียนหมายเหตุใน STATUS แทน
- ข้อ 10 การรีวิวโดยคน ต้องให้ผู้ใช้หรือหัวหน้าทำ
- ไม่ติดตั้ง Node หรือ pnpm บนเครื่องอื่น

### ความเสี่ยง

- **Hook ปฏิเสธคำสั่งปกติมากขึ้น:** ข้อ 1 อาจถามบ่อยขึ้น กันด้วยเทสต์ของคำสั่งที่ต้องผ่าน เช่น `echo "git commit"` และ `grep 'git commit'`
- **ข้อ 11 อาจเปิดช่องใหม่:** ถ้าอ่าน heredoc ผิด อาจซ่อน commit จริงได้ จึงยกเว้นเฉพาะ heredoc ที่ป้อนให้คำสั่งที่ไม่ใช่ `git`, `bash`, `sh` หรือ `eval`
- **Hook ยังอ่านแค่ข้อความ:** commit ที่อยู่ในไฟล์สคริปต์ยังผ่านได้ เป็นข้อจำกัดเดิมที่บันทึกไว้แล้ว
- **การเปลี่ยน gate เป็นเรื่องของ Tech Lead:** บันทึกเป็น ADR-0019 สถานะรอรีวิว

  จึงถามเฉพาะเมื่อโปรแกรมที่รับข้อความนั้นไม่อยู่ในรายการที่แค่แสดงหรือค้นข้อความ ได้แก่ `echo`, `printf`, `grep`, `rg`, `git` และ `Select-String`
