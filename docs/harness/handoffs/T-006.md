## สิ่งที่ยังไม่เสร็จหรือยังไม่ได้ตรวจ

- ยังไม่ได้ลองเดินตามคู่มือใหม่ตั้งแต่ต้นโดยสั่ง AI เป็นภาษาคน ตอนซ้อมผมรันคำสั่ง git เอง
- ฉากเสริม `push` ไม่ได้ซ้อม เพราะจะเด้งกล่องถามผู้ใช้
- ข้อความในคู่มือต้องแก้ตามถ้าข้อความใน `tools/gates/git-guard.mjs` เปลี่ยน

## บทเรียน

ข้อความใน heredoc ของ Bash ที่มีคำว่า `git commit -m "green(...)"` ทำให้ hook ปฏิเสธคำสั่งที่ไม่ได้ commit จริง
เพราะ hook อ่านข้อความของคำสั่ง ให้เขียนไฟล์ที่มีข้อความแบบนี้ด้วย Edit หรือ Write

## ขั้นถัดไป

ผู้ใช้เลือกว่าจะ push หรือไม่ และจะถามหัวหน้าเรื่อง merge หรือสิ่งที่ต้องดูเพิ่ม
