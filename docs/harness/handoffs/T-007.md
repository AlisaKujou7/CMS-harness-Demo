## Review

ไม่ได้รีวิวแยก เพราะเป็นการแก้สิทธิ์ 3 จุดใน workflow และพิสูจน์ด้วย CI จริง

## สิ่งที่ยังไม่เสร็จหรือยังไม่ได้ตรวจ

- **CodeQL:** log บอกว่า "Code scanning is not enabled for this repository" repo ส่วนตัวที่เป็น Private ต้องใช้ GitHub Code Security ซึ่งเสียเงิน อยู่นอกขอบเขตตาม Contract
  ทางเลือกคือเปิดบริการนั้น ทำ repo เป็น Public ซึ่งต้องถามหัวหน้าก่อนเพราะสเปกเป็น Internal หรือยอมรับเป็นข้อจำกัด
- **Mutation testing:** ในเครื่องใช้ราว 4 นาที บน runner 2 core ยังไม่จบหลังเกิน 50 นาที ยังไม่รู้ว่าช้าหรือค้าง ต้องรอ log หลังจบ
  งานนี้อยู่นอก Contract ของ T-007
- **ข้อเตือนจาก CodeQL:** `codeql-action@v3` จะเลิกใช้ในเดือนธันวาคม 2026 ควรย้ายไป v4 ในงานถัดไป

## บทเรียน

- Docker Desktop บนเครื่องนี้ดับเองได้ ก่อนรัน gate ให้ตรวจ `docker version` ก่อน ไม่อย่างนั้น coverage และ E2E ล้มโดยไม่เกี่ยวกับโค้ด
- Workflow ที่ไม่เคยรันจริงซ่อนปัญหาเรื่องสิทธิ์ไว้ การรันครั้งแรกบน GitHub จึงควรเกิดเร็ว

## ขั้นถัดไป

ผู้ใช้ตัดสินเรื่อง CodeQL และ Mutation testing และหัวหน้ารีวิว ADR-0017 กับ ADR-0018 ก่อน merge PR #1
