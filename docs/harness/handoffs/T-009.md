# Handoff: T-009

- **Ticket:** [T-009](../tickets/T-009-hook-review-2.md)
- **Commit:** `ade7ef2` red, `cbf119c` green และ commit ของเอกสารกับ Handoff นี้

## สิ่งที่เสร็จ

- Hook อ่านคำสั่งใน `bash -c`, `sh -c`, `eval`, `pwsh -Command` และ `cmd /c` และถามก่อน ถ้าโปรแกรมอื่นรันข้อความที่มี git commit
- `HUSKY=0` นับเป็นการข้าม git hook และ `red` หรือ `green` อ่านจาก `-m` แรกเท่านั้น
- ไฟล์ `.md` ใน `AIAGENT_POC/` ต้องรัน gate ใหม่
- Stamp บันทึกขั้นที่ข้าม และ hook ปฏิเสธ commit ปกติถ้าข้ามการสแกน secret
- heredoc ที่ป้อนให้โปรแกรมอื่นที่ไม่ใช่ git หรือ shell ไม่นับเป็นคำสั่ง
- CI มีขั้น `openapi` แล้ว และ `init.sh` ตรวจ Node, pnpm, Docker และ gitleaks
- `workflow.md` มีหัวข้องานที่ไม่ต้องมี Ticket และ `CLAUDE.md` แยกส่วนของ Windows
- ADR-0019

## ผลการตรวจ

- **Red:** 64 กรณี ล้ม 18 แยกกัน ดูใน Ticket
- **Green:** `git-guard.test.mjs` ผ่าน 64/64
- **Self-test:** `pnpm gate:self-test` จับได้ 32/32 รวม 2 กรณีใหม่ คือ commit ใน `bash -c` และ `HUSKY=0`
- **Gate:** `pnpm gate` รอบแรกล้มที่ Dependency CVEs เพราะ advisory ใหม่ของ picomatch ซึ่งแก้ใน T-010
  รอบหลัง T-010 ผ่านครบ 18 ขั้น (2026-11-18)
- **ลองจริงใน Claude Code:**
  - `bash -c "git commit -m 'feat(api): demo bypass'"` ถูกปฏิเสธเพราะยังไม่ผ่าน gate ซึ่งก่อนหน้านี้ hook ปล่อยผ่าน
  - `HUSKY=0 git commit -m "feat(api): demo bypass"` ถูกปฏิเสธว่า "Git hooks may not be skipped"
  - `git commit -m "feat(api): demo bypass" -m "red(api): demo"` ถูกปฏิเสธเพราะยังไม่ผ่าน gate ไม่ถูกนับเป็น `red`
- **`init.sh`:** ตรวจเครื่องผ่าน และเตือนจริงว่า Docker ไม่ทำงานในตอนนั้น

## Review

ไม่ได้รีวิวแยก งานนี้มาจากรีวิวของ AI อีกตัว ผู้ใช้เลือกได้ว่าจะรีวิวต่อหรือไม่

## สิ่งที่ยังไม่เสร็จหรือยังไม่ได้ตรวจ

- **ข้อ 4c, 4d, 9 และ 10:** อยู่นอกขอบเขตตาม Contract
- **การปลอม stamp:** ยังทำได้ บันทึกเป็นข้อจำกัดใน ADR-0019 มีแค่ CI บน GitHub ที่ปลอมไม่ได้
- **CI:** ยังไม่ได้เปิด PR ของ branch นี้ ขั้น `openapi` ใน CI จึงยังไม่ได้รันบน GitHub
- **`init.sh` บน Mac:** ยังไม่ได้ลองบนเครื่องที่รีวิวรัน และยังไม่ได้ลองกรณี Node ไม่ตรง
- **ไฟล์รีวิวต้นฉบับ:** `docs/harness/reviews/2026-11-18-harness-review.md` ที่รีวิวอ้าง ไม่มีใน repo ลิงก์อยู่ใน Ticket แทน

## บทเรียน

- รีวิวจากเครื่องมืออื่นต้องตรวจซ้ำกับ commit ปัจจุบันก่อนเชื่อ รีวิวนี้ตรวจ `96d96f1` จึงมีข้อที่แก้ไปแล้ว
- Advisory ใหม่ทำให้ gate ล้มได้โดยไม่มีอะไรในโค้ดเปลี่ยน ควรรัน gate ก่อนเริ่มงาน ไม่ใช่แค่ตอนจบ
